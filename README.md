# Network QA & Playwright Portfolio

By Manoj Kumar Jena

A personal learning and demonstration project covering network
and CPE testing, manual QA, and Playwright automation with TypeScript.

## Project Roadmap

- Manual test cases for router, gateway, and CPE functionality
- DHCP, DNS, NAT, IPv4/IPv6, and Wi-Fi validation
- Throughput, latency, and packet-loss troubleshooting labs
- Playwright UI automation using TypeScript
- REST API testing
- GitHub Actions for automated test execution
## Project Status

Initial setup. Test cases, labs, and automation examples will
be added progressively.

## About This Project

All examples use simulated environments or public demo applications.
This repository contains no proprietary client code or confidential data.
